# 颠覆文字

王伯伦原创动效集。这一系列的核心理念：**文字不只是"显示"出来的**，而是用**出人意料的呈现方式**去表达文字——文字本身就成为一个物体、一段数据、一片风景、一群生命。

## 版本一览

| 文件 | 方向 | 表达 |
|------|------|------|
| `颠覆文字1水字.html` | ① 文字变成物体 | "水"字由无数水滴滴落汇聚而成，又化开滴落，字即水 |
| `颠覆文字2自我拆解.html` | ② 自我拆解 | 汉字拆成偏旁散开又拼回，表达"解构-重构" |
| `颠覆文字3水面倒影.html` | ③ 3D镜像倒影 | 字立水面，下方是翻转+模糊+波动的倒影，"水中月" |
| `颠覆文字4数据流.html` | ④ 动态数据流 | "流逝"由滚动跳动的数字/字符构成，像数据瀑布 |
| `颠覆文字5液态金属.html` | ⑤ 材质构成 | 字像液态金属，表面流动金属光泽，底部熔化滴落 |
| `颠覆文字7活字.html` | ⑦ 文字是活物 | "生"字由无数小生物聚成，各自蠕动呼吸 |
| `颠覆文字8冲破平面.html` | ⑧ 打破平面 | 字有 3D 景深远近，部分探出屏幕，像全息投影 |
| `颠覆文字9生长.html` | ⑨ 随时间生长 | "木"字按笔顺一笔一笔描边生长出来，像藤蔓 |
| `颠覆文字10字里星空.html` | ⑩ 与场景融合 | "夜"字里装着一片闪烁星空，字本身就是画面 |

## 用法

每个 HTML 自包含（HTML+CSS+JS），浏览器双击即预览。嵌入网页时 CSS/结构/JS 分别取出放入对应位置即可。

## 可扩展

- ① 水字：改 `TEXT` 换字（可换成"雨""流"等水的字）
- ② 拆解：`WORDS` 数组加字，按偏旁拆
- ④ 数据流：改 `TEXT`、`STEP`（密度）
- ⑨ 生长：需手写新字的 SVG 描边路径（按笔顺）
- ⑩ 字里星空：改 `TEXT` 换字，改 `.sky` 的 `background-image` 可换成海/山/森林等场景
