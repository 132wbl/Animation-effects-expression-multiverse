# 时间表达

王伯伦原创动效集。**不局限于一种时间形式**——同是表达时间，用完全不同的视觉语言呈现。每种是一个独立的 HTML 动效，放任务栏 / 状态栏 / 桌面 / 界面任一位置都行。

## 已收录的表达方式

| 文件 | 表达方式 | 理念 |
|------|---------|------|
| `时间表达1沙漏.html` | 沙漏 | 时间 = 流沙，沙子随一天流逝从上到下，直观看到"时间在走" |
| `时间表达2文字诗.html` | 文字诗 | 时间 = 诗意，每个小时换一句氛围诗句（24 句），随刻而变 |
| `时间表达3圆环进度.html` | 圆环进度 | 时间 = 进度，一圈 = 24 小时，实时填充，标注早/午/晚 |
| `时间表达4极简禅.html` | 极简禅 | 时间 = 呼吸，一根时光之轴 + 呼吸圆点滑动，极简留白 |
| `时间表达G燃烧火焰.html` | 燃烧火焰 | 时间 = 火焰，时间文字像火苗一样跳动、摇曳、燃烧 |

## 各表达详述

### ① 沙漏
- 老式沙漏造型，上方沙随一天减少、下方沙增加，中部有落沙细流
- 24 小时 = 一漏沙，直观的流逝感
- 时间 + 日期显示在下方

### ② 文字诗
- 主画面是一句随小时变化的诗句（如"晨光正好，咖啡正香""夜深人静，星光点点"），淡入淡出切换
- 时间、星期、日期以小字放在底部
- 用文字的温度表达此刻，而非冷冰冰的数字

### ③ 圆环进度
- 一圈进度环 = 24 小时，从 0% 实时填到 100%，渐变发光
- 环中心显示时分秒，下方标注当前时段（深夜/上午/下午/晚上）及日期
- 时间 = 一件正在完成的事

### ④ 极简禅
- 一根竖刻度轴（24 小时），一个金色呼吸圆点沿轴滑动，带扩散光晕
- 极细极简的数字 + "此刻 · 即永恒"禅意标语
- 时间 = 一条不断延伸的线，此刻是一个点在移动

### G 燃烧火焰（动态系列）
- 时间文字做成火焰：三层叠加（外橙 / 中橙黄 / 内黄白芯），各层不同模糊 + 摇曳
- 整体上下跳动 + 左右晃动，火星从底部飘散，像真火在烧
- 时间 = 燃烧本身，热烈、不断

### J 3D 立体旋转（动态系列）
- 时间做成一个 6 面 3D 立方体，绕 Y 轴持续旋转，有立体透视感
- 外圈一个旋转的光晕环（带流动光点）增强空间感
- 下方并行显示大号时分秒平面数字，日期/星期在最下

### J v1.1 3D 分片旋转（动态系列，修正重叠）
- 原 J 的 6 面立方体旋转时各面互相遮挡重叠，观感杂乱
- **v1.1 改为每块数字独立成片**：时分 4 个数字 + 冒号各是一块 3D 立体分片，并排横排、互不重叠
- 每块绕自己的 Y 轴旋转，且**各块相位错开**（不同速度 + 延迟），有波浪层次
- 冒号那块不转保持稳定，外圈椭圆旋转光晕环增强空间感

### K v1 拼图盘（已被否，保留对照）
- 24 块盘＝24 小时，已过去实心、当前块青色呼吸并按分钟填充、未来虚线空槽；指针移上来整盘填满，五位数字块飞入拼出 `HH:MM`
- **被否的原因**：拼图盘和时间牌是两套东西，各演各的——拼图只是背景，时间还是另外一块牌子浮在上面。不是"拼图拼出来的时间"
- 文件保留在库里做对照，不再更新

### K v2 拼图时间（动态系列，第三批 · 现行）
- **时间本身就是一幅 24 块的拼图**：此刻的 `HH:MM` 整幅字被切成 6×4＝24 块（24 块也正好是 24 小时），块与块之间是拼图的缝
- **平时读不出任何时间**：24 块摊在画面上，各自歪着、各自慢慢漂，每块只露一小段笔画碎片；缺一块就不成字，所以整体永远读不出来
- **指针移上来**：24 块从左上往右下错峰飞回自己的位置，咬合成完整的 `HH:MM`；字后面浮起一层极淡的光
- **微生命**：没拼好的块一直在缓慢漂移、轻微自转；指针靠近时它们轻轻躲开，像桌上还没收拢的东西
- **余韵**：指针移开不立刻散，拼好的样子留 1.2 秒才松开
- **秒也在这块盘里**：每过一秒，整盘拼图的缝轻轻亮一下——秒不需要另外一根进度条
- **每分钟重拼一次**：分钟一跳，那一分钟里真的变了的块会当场弹出去、再咬回来。时间在换，你看得见，不是摆着不动
- **一天走到哪**：看拼图缝的亮度——已过去的小时的缝是焊上的（淡青），当前这一小时的缝在一呼一吸，未来的缝是冷的。这是盘上唯一泄露"进度"的地方，但不是数字
- 触屏/无 hover：点一下自己拼 4 秒；系统开"减少动态效果"时直接静态显示
- 时间 = 一件被拼起来的东西；**你去看它，它才拼给你看**

## 用法

每个 HTML 自包含（HTML+CSS+JS），浏览器双击即预览。

### 直接嵌到别人的网页里（K 拼图 v2 支持）

一行 iframe，复制过去就能用：

```html
<iframe src="时间表达K拼图v2-L.html#iframe" width="760" height="420"
        frameborder="0" scrolling="no"
        style="border:0;background:transparent"></iframe>
```

- `#iframe`：**透明底**，去掉日期和签名，只剩拼图本身，垫在别人任何底色上都立得住（每块自带暗玻璃底）
- 整幅舞台会**按容器等比缩放**：760×420、整条 1200×300 的状态栏、几百像素的小卡都完整不裁
- `#demo` 看拼好的样子；`#iframe-demo` 两个模式一起用（透明 + 直接拼好）
- 想做成 `<puzzle-clock></puzzle-clock>` 这种「一行标签、不套 iframe」的组件版，需要另出一份 JS，说一声就行

其余表达（1/2/3/4/G/J）：把 CSS / 结构 / JS 分别取出来，放进自己页面的对应位置即可。
