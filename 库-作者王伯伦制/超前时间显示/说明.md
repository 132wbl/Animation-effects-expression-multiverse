# 超前时间显示

王伯伦原创动效集。**不局限于钟表**，用多种超前的视觉语言表达时间，设计为可放在任务栏 / 状态栏 / 界面顶栏位置的时间显示组件。

本文件夹统一收录**超前时间显示动效的全部版本**，每个版本一个文件，版本号递增。

## 版本一览

| 版本 | 文件 | 视觉风格 | 动效亮点 |
|------|------|---------|---------|
| **v2** | `超前时间显示v2.html` | 粒子流光 | 全屏粒子流场（就近连线成网）+ 大号渐变流光时间 + 彩色光晕秒数 |
| **v3** | `超前时间显示v3.html` | 全息胶囊 | 紧凑全息胶囊 pill + 全息扫光 + 渐变时间 + 底部呼吸光带 |

## 各版本说明

### v2 粒子流光
- 背景 Canvas 粒子流场，粒子就近连线成光网，随时间流动
- 大号渐变流光时间居中，秒数单独用粉色光晕大字
- 适合做桌面小组件 / 全屏时钟 / 锁屏

### v3 全息胶囊
- 最紧凑，一颗全息渐变胶囊，放状态栏 / 通知中心位置
- 全息扫光扫过 + 渐变时间 + 底部呼吸光带
- 时间 + 秒 + 星期 + 日期紧凑排列

## 用法

每个 HTML 都是自包含的（HTML+CSS+JS），浏览器双击即可预览。嵌入网页时：CSS 入样式表、结构入页面、JS 入 `<script>` 尾部。

## 可调参数（各文件内 CSS 变量 / 常量）

- 流光渐变速度：`animation: flow 6s linear infinite`（改秒数）
- 粒子数量：`ps` 数组长度（v2）
- 玻璃模糊强度：`backdrop-filter: blur(16px)`（v3）
