# 文字动效

王伯伦原创动效集。这一系列是**页面内容里的文字动效**——用于标题、标语、正文、按钮等，动效是手段、内容表达是目的，收着做、不炫技。

## 版本一览

| 文件 | 效果 | 表达 |
|------|------|------|
| `文字动效1打字机.html` | 打字机循环 | 逐字打出、停留、删除、换句循环，光标闪烁，像终端/聊天输入 |
| `文字动效2描边书写.html` | 描边书写 | 空心描边字，笔尖扫过从左到右"描"出来（保留版） |
| `文字动效G描色填充.html` | 描色填充 | 空心字从下往上被深色填满，像水位上升，表达"完成/推进" |
| `文字动效H聚焦清晰.html` | 聚焦清晰 | 字从模糊放大逐字聚焦到清晰，像镜头对焦，表达"觉醒" |
| `文字动效M墨迹晕开.html` | 墨迹晕开 | 墨团从中心向外晕开成字，有浓淡墨韵，像墨滴入水（重点保留） |
| `文字动效P划线勾重点.html` | 划线勾重点 | 关键词下方一道线画出 + 高光扫过，标记重点 |
| `文字动效Q点阵浮现.html` | 点阵浮现 | 文字由小点从左到右逐列点亮浮现，克制不迸散 |
| `文字动效R光影扫过.html` | 光影扫过 | 一束斜光扫过整行文字，扫过处变亮发光 |
| `文字动效A逐字点亮.html` | 逐字点亮 | 每个字依次亮起发光，像霓虹字幕逐字点亮 |

## 用法

每个 HTML 自包含（HTML+CSS+JS），浏览器双击即预览。嵌入网页时 CSS/结构/JS 分别取出放入对应位置即可。

## 可扩展

- 打字机：改 `SENTENCES` 数组换句子
- 描色填充：改 `.fill` 和 `.ink span` 两处文字
- 划线勾重点：给要强调的词包上 `<span class="kw">…</span>`
- 聚焦清晰：给每个字加一个 span，并同步 nth-child 延迟
- 墨迹晕开：改 `.ink` 里的字（多字时 background-size 起始值需调大）
- 光影扫过：改 `.shine` 的 data-text 和文字内容
