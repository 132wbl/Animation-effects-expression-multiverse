# 库 — 作者王伯伦

王伯伦原创动效库。每个动效为自包含 HTML（HTML+CSS+JS），浏览器双击即可预览；嵌入网页时把 CSS/结构/JS 分别取出放入对应位置即可。

## 各系列说明

### 钟表
- 实时挂钟，钟摆摆动，可设定到点敲钟
- v1 初版 / v1.1 写实外观+真实钟声 / v1.2 修正指针居中+更精致

### 超前时间显示
- 放在任务栏/状态栏位置的紧凑时间显示，玻璃拟态 + 霓虹 / 全息胶囊

### 时间表达
- 用不同视觉语言表达时间：沙漏（流沙）、文字诗（诗意）、圆环（进度）、极简禅（呼吸）、火焰（燃烧）、3D 立体旋转、拼图等

### 文字动效
- 页面内容文字动效：打字机循环、描边书写、描色填充、聚焦清晰、墨迹晕开、划线勾重点、点阵浮现、光影扫过、逐字点亮

### 颠覆文字
- 颠覆性文字表达：①水字 ②自我拆解 ③水面倒影 ④数据流 ⑤液态金属 ⑦活字 ⑧冲破平面 ⑨生长 ⑩字里星空

## 版本规范

- 同一个动效的所有版本收在同一个文件夹内，文件名带版本号，互不覆盖
- 原创作品不加作者前缀（已在本库，均为王伯伦原创）
